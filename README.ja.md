# VspoDex 🎮

[English](README.md) | [繁體中文](README.zh-TW.md) | 日本語

**ぶいすぽっ！ (VSpo)** のVTuber配信を簡単にチェック。VspoDexは、HolodexとTwitchのデータを集約して、お気に入りメンバーの配信状況をリアルタイムでお知らせするブラウザ拡張機能です。

## 🚀 このプロジェクトについて
この拡張機能は、ぶいすぽっ！コミュニティのために開発されました。YouTube（Holodex API経由）とTwitchの配信状況、配信予定スケジュール、チャンネル情報をシンプルかつ効率的にチェックできます。

> [!IMPORTANT]
> 本拡張機能を正常に動作させるには、Holodex APIキーの設定が必要です。設定手順は非常に簡単です。拡張機能内の設定ページにある案内に従って設定を行ってください。

## ⚙️ 主な機能

- **【新機能】お気に入り自動開く**：ポップアップ側サイドバーの下部にある稲妻ボタンでお気に入りのVTuberが配信開始した際に自動でタブを開くことができます（アクティブ/バックグラウンド動作の選択、および配信終了時に自動でトリガーを再有効化/循環する実験的機能、さらに最大ストリームストリーク数の上限設定をサポート）。
- **【新機能】配信予定のウォッチリスト**：配信予定のカードにあるアラームボタンをクリックすると、配信開始時（または予定時刻）に自動で配信ページを開くことができます。
- **【新機能】メンバーカラーテーマ**：15人のぶいすぽメンバーの公式 VSPO! GEAR キーボードデザインに基づいたカラーテーマを搭載（ライト/ダークモード、ドット柄の背景装飾に対応）。
- **【新機能】タブの並べ替え**：設定ページにてドラッグ＆ドロップで、ポップアップのサイドバータブ（配信中、メンバー、配信予定、過去配信）の表示順序を自由に変更できます。
- **【新機能】メンバータブ**：フォロー中のチャンネルをお気に入り、ぶいすぽJP、ぶいすぽEN、ぶいすぽ公式などのグループに分けて、チャンネル登録者数順に一覧表示します。メンバーをクリックすると、そのメンバーの過去配信アーカイブを表示できます。
- **一元化された配信追跡**：YouTube（Holodex API経由）とTwitchのアクティブな配信やスケジュール予定を同時にチェックできます。
- **チャンネルのカスタマイズ**：デフォルトのぶいすぽメンバーはもちろん、YouTubeのチャンネルIDを使ってお好みのVTuberチャンネルを追加・追跡できます。
- **ホロライブ・にじさんじ検索機能**：検索および自動補完機能を内蔵。ホロライブやにじさんじのメンバーを検索して簡単にお気に入り追加できます。
- **過去配信のアーカイブ表示**：無限スクロールや配信時間のバッジ表示に対応。YouTubeのコラボ配信非表示フィルタリングや、Twitchの過去配信（実験的機能、デフォルトで有効）表示をサポートしています。
- **デザインのカスタマイズ**：インターフェーステーマ（ダーク、ライト、システム同期）、フォントサイズ、配信の並び替え方法を自由に設定できます。
- **多言語対応**：英語、日本語、繁体字中国語（繁體中文）に完全対応しています。

## 🌐 言語設定
VspoDexは多言語に対応しています。設定画面の「外観」セクションから、お好みの言語に変更できます。
- 🇺🇸 **English** (デフォルト)
- 🇯🇵 **日本語**
- 🇹🇼 **繁體中文**

## 🔑 必要要件
拡張機能を正常に利用するには、以下が必要です。
- **Holodex APIキー**：YouTubeの配信データを取得するための無料のAPIキーが必要です。
- **Twitchログイン**：拡張機能内でTwitchアカウントにログインする必要があります。これは配信状態を確認するAPIアクセスのためにのみ使用され、**個人情報やアカウントデータの収集・保存は一切行いません。**

## 🛠️ Holodex APIキーの取得方法
APIキーは無料で簡単に取得できます。
1. [holodex.net](https://holodex.net) にアクセスしてログインします。
2. 右上のプロフィールアイコンをクリックし、**Account Settings**（アカウント設定）を選択します。
3. ページ下部の **API Key** セクションまでスクロールします。
4. **新規APIキーを発行する** ボタンをクリックしてキーを発行します。
5. 発行されたキーをコピーし、**VspoDexの設定ページ** に貼り付けます。
